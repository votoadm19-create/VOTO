# Regras Permanentes para Agentes (AGENTS.md) - Projeto VOTO

Este arquivo define as diretrizes obrigatórias e permanentes para a atuação de agentes de IA neste repositório.

## Regras Permanentes

1. Antes de implementar qualquer funcionalidade, analise a arquitetura e os arquivos relacionados.
2. Preserve as funcionalidades existentes e evite regressões.
3. Não faça alterações fora do escopo solicitado.
4. Não remova arquivos, dependências, funcionalidades ou dados sem autorização explícita.
5. Não execute git commit, git push, git reset, git clean ou operações destrutivas sem autorização.
6. Não altere configurações de produção, banco de dados ou variáveis de ambiente sem autorização.
7. Nunca exponha credenciais, tokens, senhas ou dados sensíveis.
8. Priorize código simples, organizado, reutilizável e seguro.
9. Considere compatibilidade com a arquitetura e tecnologias já utilizadas pelo projeto.
10. Execute testes e verificações pertinentes após implementar alterações.
11. Informe quais arquivos foram modificados, o que foi feito e os resultados dos testes.
12. Quando houver dúvidas sobre requisitos, pergunte antes de implementar.
